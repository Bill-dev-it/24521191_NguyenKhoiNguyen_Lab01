## WBS Task T-01

- **Task:** Build the semantic DOM architecture and accessibility contract.
- **Scope:** Create the landmark hierarchy, implement the skip link, and use semantic HTML elements.
- **Acceptance criteria:**
	- The page contains no `div` elements.
	- A skip link targets `#main-content`.
	- The page has one `header`, one primary `nav`, one `main`, and one `footer` landmark.
	- Each content section has a unique `id` and a heading.
